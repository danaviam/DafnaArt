ניהול הגלריה

עדכנו כאן מחירים וסמנו ציורים כ"נמכר". השינויים מופיעים מיד בגלריה שלמטה - אבל רק בדפדפן הזה, האתר האמיתי עדיין לא השתנה.
כדי שכולם יראו את השינויים: לחצו על "הורדת קובץ מעודכן", ואז העלו את הקובץ שהתקבל ל-GitHub במקום ה-index.html הקיים (Add file → Upload files → Commit).
השינויים נשמרים זמנית בדפדפן ולכן ישרדו רענון של הדף, אבל ייעלמו כשתסגרו את הכרטיסייה. שימו לב: קוד הגישה אינו אבטחה אמיתית (הוא גלוי בקוד המקור) - הוא רק מונע כניסה מקרית.
